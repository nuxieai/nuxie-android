# Changelog

## 0.1.2

Updates the embedded runtime to [android-runtime-v0.4.15](https://github.com/nuxieai/nuxie-runtime/releases/tag/android-runtime-v0.4.15).

- Improves Experience layout when content resizes, scrolls, or changes visibility.
- Improves CSS box painting, rounded clipping, borders, and pointer handling.
- Adds text underlines and strikethroughs, including updates while an Experience runs.
- Fixes frame writes when a component-list row has been removed.

Update the SDK dependency to 0.1.2; no host-app API changes are required.

Includes the Material dependency in the Bazel SDK/test and Maven publication paths, matching Gradle and supporting native bottom-sheet presentation.
